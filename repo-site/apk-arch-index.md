# apk repository — `__ARCH__`

OpenWrt 25.12+ (apk) repository for the `__ARCH__` architecture. The router
fetches the signed index and the packages from this directory; apk matches
the package arch against the device's own arch exactly, so a device uses only
its own subdirectory.
