# trusttunnel feed — `__ARCH__`

The signed package feed for the `__ARCH__` architecture. The package
manager of the enclosing release tree reads this directory: apk (OpenWrt
25.12+) fetches `packages.adb`, opkg (22.03–24.10) appends `/Packages.gz`
to the feed URL.
